API

Extract media links

GET /api/download?url={video_url}
ParameterRequiredDescription
urlYesFull URL of the video.
// Node / browser
const url = "https://youtube.com/watch?v=dQw4w9WgXcQ";
const r = await fetch(`/api/download?url=${encodeURIComponent(url)}`);
const d = await r.json();
d.data.medias.forEach(m => console.log(m.label, m.url));

Use responsibly. Only download content you own, that is public domain or Creative Commons, or that qualifies as fair use in your jurisdiction. Downloading copyrighted material may breach platform terms and copyright law. Extracted YouTube links expire within roughly six hours and are tied to the requester's IP address — consume them promptly.
